# Iteración 1 – HTML + CSS (Maquetación base)

Landing page de Bookmark creada solo con **HTML y CSS**.

---

## 🚀 Cómo usar este proyecto

1️⃣ **Clonar el repositorio**
```bash
git clone <URL-de-tu-repo>
cd bookmark-landing-page
```

2️⃣ **Abrir el proyecto**
- Abre el archivo `index.html` en tu navegador  
  o usa la extensión **Live Server** desde VS Code.

3️⃣ **Explorar el código**
- Carpeta `assets/` → imágenes  
- `index.html` → estructura  
- `style.css` → estilos base

---

## 🧩 Qué incluye
- HTML semántico (header, main, footer)
