# 🧭 Sprint 1: Maquetación Bookmark Landing Page

## 📘 Descripción del Proyecto

Este proyecto consiste en construir una **landing page para Bookmark**, siguiendo los diseños proporcionados en la carpeta `/designs`.  
El objetivo principal es **aprender y aplicar buenas prácticas de maquetación**, **diseño responsive**, **accesibilidad web (WCAG)** y **organización de código**, trabajando de forma iterativa y profesional.

---

## 🎯 Objetivos de Aprendizaje

- Dominar la **semántica HTML5** para crear una estructura clara y accesible.
- Aplicar **buenas prácticas de CSS** para mantener un código limpio, modular y escalable.
- Implementar un diseño **responsive Mobile First** utilizando **Flexbox** y **CSS Grid**.
- Incorporar **principios de accesibilidad**: atributos ARIA, contraste de colores, etiquetas `alt` descriptivas.
- Familiarizarse con el **flujo de trabajo en Git y GitHub**, incluyendo ramas, commits y despliegue en GitHub Pages.

---

## 🧰 Herramientas y Tecnologías

- **HTML5** → estructura semántica del contenido.
- **CSS3 / TailwindCSS** → estilos, layout y diseño responsive.
- **VS Code** → editor principal.
- **Git + GitHub** → control de versiones y colaboración.
- **GitHub Pages** → despliegue de la versión final.
- **Herramientas de validación** → W3C Validator, Wave, contrast checkers.

---

## 🚀 Pasos para Ejecutar el Proyecto

### 1️⃣ Clonar y configurar el repositorio

```bash
git clone https://github.com/IT-Academy-BCN/bookmark-landing-page.git
cd bookmark-landing-page
git remote rm origin
git remote add origin <URL-de-tu-repositorio>
2️⃣ Instalar dependencias
bash
npm install
3️⃣ Iniciar el entorno de desarrollo
Abre el proyecto en tu IDE (VS Code recomendado).

4️⃣ Visualizar el proyecto
Abre index.html en el navegador o utiliza una extensión como Live Server para ver los cambios en tiempo real.

🧱 Desarrollo Iterativo
🔹 Iteración 1 – HTML y CSS base
Crear la estructura semántica con <header>, <main>, <footer>, etc.

Implementar la navegación principal (logo, menú, botón de login).

Añadir las secciones: Hero, Features, Download Extension, FAQ y Footer.

Aplicar estilos responsive y principios Mobile First.

Validar el código con herramientas como W3C Validator.

♿ Accesibilidad (WCAG)
Usar aria-label en elementos interactivos.

Incluir texto alternativo (alt) descriptivo en imágenes.

Garantizar contraste adecuado entre fondo y texto.

Asegurar navegación por teclado funcional.

💡 Buenas Prácticas
Commits frecuentes y descriptivos siguiendo el formato convencional:

bash
feat: añade sección FAQ
fix: corrige visibilidad del menú móvil
style: mejora espaciado y tipografía
Uso de clases CSS descriptivas (.btn-primary, .hero-section, etc.).

Código validado, comentado y organizado por secciones.

Diseño adaptable a móviles, tablets y escritorio.

🌐 Despliegue en GitHub Pages
Una vez finalizado el proyecto:

bash
git checkout main
git merge feature/vanilla-implementation
git push origin main
